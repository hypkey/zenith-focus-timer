# Ambient Sounds

Place MP3 loop files here for the soundscape mixer:

- `rain.mp3` - Rain ambience
- `cafe.mp3` - Cafe / coffee shop ambience
- `fireplace.mp3` - Fireplace crackling
- `forest.mp3` - Forest / nature sounds
- `ocean.mp3` - Ocean / waves
- `white_noise.mp3` - White noise

Use seamless loops (same start and end) for best results. Free sources: Freesound.org, Pixabay, or similar.
